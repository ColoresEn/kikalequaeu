# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Administrators use the admin area to read messages submitted through the contact interface and to browse registered users.

## Product Purpose

The admin area supports reviewing contact messages and managing registered user accounts.

## Operating Context

Administrators review messages in the interface and can open a registered user's record to edit it.

## Capabilities and Constraints

- Messages include a sender name, email, topic, message, and submission date.
- Administrators can delete messages.
- Administrators can browse registered users, open a user to edit their details, and delete a user.
- Existing access is restricted to users with the ADMIN role.

## Evidence on Hand

- Contact message data and user account data are loaded from the application's database.
- The contact form is the source of messages shown in the admin area.
